Connect your Are.na account

This reader calls the Are.na v3 API directly from your browser. It needs a personal access token so it can see who you follow.

  1. Go to your Are.na applications / developer settings.
  2. Create an application (or open an existing one) and copy your Personal Access Token.
  3. Paste it below. It is stored only in this browser (localStorage) and sent only to api.are.na.

Tip: the scope=following search may require an Are.na Premium account.
